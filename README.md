# Fancier Midgard Branches

Replaces Midgard's ugly fence branches with thinner branches that connect to wood, leaves and ground.

Minecraft 1.21.1, NeoForge 21.1.265 or newer in the 21.1 series, and Midgard 1.1.0 are required. Install this on the client.

Leaves connect in every direction. Horizontal branch runs take priority over upper branch connections. Roots connect to soil, sand, gravel and stone. Collision and world generation stay as Midgard defines them.
